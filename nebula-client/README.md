# Nebula Client (Fabric 1.21.11)

Singleplayer utility client. Open the GUI with **Right Shift**.

Modules: Reach, Hitboxes, Shield Breaker, Stun Slam, TNT Minecart, Stash Finder, Base Finder, Farm Finder,
plus HUD (watermark, array list, finder arrows).

Gameplay modules only run in singleplayer worlds.

## Build the jar with GitHub
1. Create a repo and upload everything in this folder (including `.github/workflows/build.yml`).
2. Open the Actions tab, wait for the build, download the `nebula-client` artifact and unzip it.
3. Put the jar plus Fabric API into `.minecraft/mods` (Fabric Loader for 1.21.11).
